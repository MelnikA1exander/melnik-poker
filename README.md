# Poker Coach — тренажёр домашней игры

Тренажёр префлопа (режимы «Профиль», «Префлоп», «Полная раздача»), один файл `index.html`, выложен на GitHub Pages.

Результаты завершённых сессий «Профиля» отправляются в Google Таблицу через веб-приложение Apps Script (адрес — константа `ENDPOINT` в начале `index.html`). Код приёмника и инструкция по развёртыванию — в папке `apps-script/`.
