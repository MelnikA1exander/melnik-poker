# Как подключить таблицу результатов (5 минут)

1. Создай новую Google Таблицу, например «Melnik Poker — результаты».
2. В меню таблицы: **Расширения → Apps Script**.
3. Удали всё, что там есть, и вставь код из `apps-script.gs`. Нажми значок дискеты (Сохранить).
4. Справа сверху **Развернуть → Новое развертывание**.
   - Тип (шестерёнка): **Веб-приложение**.
   - Выполнять как: **Я**.
   - Кто имеет доступ: **Все** (именно «Все», без входа в аккаунт, иначе игроки не смогут отправлять).
5. Нажми **Развернуть**, разреши доступ своему аккаунту (Google предупредит, что приложение не проверено: «Дополнительно → Перейти»).
6. Скопируй **URL веб-приложения** (заканчивается на `/exec`) и пришли его мне вместе со ссылкой на саму таблицу.

Проверка: открой URL `/exec` в браузере — должно показать `{"ok":true,"sheet":"Сессии"}`, а в таблице появится лист «Сессии».

## Как обновить скрипт (адрес /exec не меняется)

1. В таблице: **Расширения → Apps Script**.
2. Замени весь код на новый `apps-script.gs`, сохрани.
3. **Развернуть → Управление развертываниями** → карандаш у текущего развертывания → «Версия»: **Новая версия** → **Развернуть**.
   Именно так, а не «Новое развертывание»: тогда адрес `/exec` останется прежним.

## Хранение и лимиты

- Лимит Google Таблицы — 10 млн ячеек, считаются все ячейки сетки, даже пустые. Скрипт создаёт листы ровно по ширине заголовка и добавляет строки по мере записи.
- «Сессии» — полный архив: одна строка на тест, все решения в колонке «Решения (JSON)». Это источник истины.
- «Раздачи профиля» — указатель: одна строка из 3 ячеек на решение (время, ключ «аккаунт/тест/№», раздача текстом). По ключу раздача находится в «Сессиях».
- На тест уходит примерно 180 ячеек, то есть таблицы хватит примерно на 50 тысяч тестов (2,5 млн раздач).
- `compactStorage` (запуск вручную) переводит старые данные в этот формат, обрезает пустые ячейки и пишет в журнал, сколько ячеек занято. `cellsUsed` — только посчитать.
